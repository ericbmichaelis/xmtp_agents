# XMTP Business Context

Use this document for relevance checking and to ground all content in XMTP's actual positioning.

## What XMTP Is

XMTP is the open messaging protocol for agents and apps. It provides encrypted, decentralized communication infrastructure that any application or AI agent can plug into — regardless of which model, framework, or blockchain they use.

## Core Thesis

XMTP is the agent communication layer. As AI agent ecosystems fragment into competing harnesses (Claude Code, Codex, Gemini CLI, OpenClaw), each becomes a silo. XMTP sits beneath all of them as the open protocol that lets agents discover, message, and transact with agents they didn't build. This is the TCP/IP argument: everyone builds their own systems, but they all need a shared network layer.

## What XMTP Actually Does

- End-to-end encrypted messaging (quantum-resistant, as secure as Signal)
- Works with any digital identity (wallets, passkeys, DIDs, ENS, Bluesky handles)
- Programmable group chat (agents can join groups, moderate, transact)
- Fully decentralized (multi-node, no single point of failure)
- Agent SDK for building AI agents that communicate over the protocol
- MCP integration so any LLM coding assistant can send/receive XMTP messages

## Key Products & Partners

- **Convos** (convos.org) — the flagship messaging app built on XMTP. "Bring Your Own Agent" model where users add AI assistants to group chats.
- **World** (worldcoin.org) — 38M+ users. World Chat runs on XMTP. World Build 3 hackathon is an active partnership with a dedicated messaging track.
- **OpenClaw** — open-source agent harness with 200K+ GitHub stars. XMTP skill lets any Claw connect to the network with one command.
- **Bankr** — financial infrastructure for agents. Agentic wallets + payments in chat.
- **Switchboard** — global network of IRL builder spaces for XMTP developers (SF, NYC, Nashville, Austin, Tokyo, and 14+ more cities via Malin partnership).

## Growth Strategy (Three Pillars)

1. **Frameworks (supply)** — OpenClaw, Claude Code, Codex skills/integrations make it easy to build agents on XMTP
2. **Convos (demand)** — makes it easy for humans to talk to those agents
3. **World (distribution)** — 38M+ verified humans and a mini app ecosystem building on XMTP-powered chat

## Target Audience

Developers building AI agents, mini apps, and messaging applications. Ranging from solo devs shipping with Cursor/Claude Code to teams at companies like PartyDAO, Drop Wallet, Holdstation. Also: AI infra builders who care about interoperability and open protocols.

## Competitive Landscape

- **Waku** (Status/Logos messaging layer)
- **Push Protocol** (notifications/messaging)
- **DSCVR** (social)

XMTP differentiates on: quantum-resistant encryption, agent-native design (Agent SDK), identity flexibility (any DID, not just wallets), and production-grade group chat at scale.
